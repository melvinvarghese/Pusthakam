# Pusthakam — starter brand assets

## Included
- `pusthakam-icon.svg` — app icon / symbol
- `pusthakam-horizontal.svg` — primary horizontal lockup
- `pusthakam-stacked.svg` — stacked lockup
- `pusthakam-monochrome.svg` — single-colour print variant
- `pusthakam-dark-background.svg` — light logo for dark surfaces

## Brand colours
- Forest green: `#123F35`
- Secondary green: `#1D5A4C`
- Copper: `#B96B32`
- Warm ivory: `#F7F4EC`
- Muted text: `#66736D`

## Typography
The wordmark uses Georgia / Times New Roman as a broadly available serif fallback.
The Malayalam line requests Noto Serif Malayalam / Noto Sans Malayalam where installed.
For pixel-identical rendering across systems, convert the chosen typefaces to outlines
in a vector editor after selecting and licensing the final fonts.

## Important production notes
These are editable vector SVG starter assets, not trademark clearance or a final
registered identity. Check the Malayalam rendering on target systems. The SVG icon
is intentionally simple so it remains legible at small sizes. Before release, export
platform-specific PNG/ICO/ICNS sizes and test the icon at 16, 24, 32, 48, 128 and 256 px.
