First-run configuration

When you launch Pusthakam for the first time, an offline setup wizard guides you through naming your library, setting your default currency (such as INR, USD, EUR), establishing loan policies (loan period, renewal limits, fine rates), and creating an administrator password. You will receive an offline recovery token; keep it in a safe place.
