Get Pusthakam

Pusthakam 0.1 is being tested and is not available to download yet. The first public release will be a signed installer for Windows 10 and 11.

Follow the first release on GitHub

How to be told when it is ready

  1. Open the Pusthakam page on GitHub. You need a free GitHub account.
  2. Click Watch, then Custom, tick Releases and click Apply.
  3. GitHub will email you when a release is published.

If you run a library and would like to try Pusthakam before then, see becoming a pilot library.

What is left before the first release

  • Install and use it on a fresh Windows computer, from setup to uninstall.
  • Test with real barcode scanners, label printers and a real Koha export.
  • Keep more automatic backups (a week, a month and a year back).
  • Sign the installer so Windows trusts it, and publish the licence terms.
  • Write a short guide for librarians.

The status page has the details.

What you will need

ComputerWindows 10 or 11, 64-bit. macOS and Linux versions are planned.
ScreenAt least 1024 × 640
InternetNot needed
Barcode scannerOptional. Any USB scanner that types like a keyboard.
Other devicesOptional. Phones, tablets or computers on the same Wi-Fi can use the public catalogue and staff pages in a browser.

Under the hood

Pusthakam is built with Tauri 2, Rust, SQLite, React and TypeScript. Please do not use a development build as the only record of a working library.
