# Splash quotation sources

## Status

The startup picker and its 113-entry local catalogue are implemented. The catalogue is a **curated working set**, not yet a completed source audit. It must not be described as 113 source-verified quotations until every entry has a primary-source locator and rights/edition review.

This distinction is deliberate: Pusthakam must not present uncertain wording or attribution as fact.

## Completion rule

For each entry, record the stable ID, exact text, author, original work, edition or translator when relevant, a primary-source URL and a locator. Remove any entry whose wording or attribution cannot be substantiated. Only then change the catalogue status to **source verified**.

The runtime application remains fully offline: references in this document are an audit trail only and are never fetched by Pusthakam.
